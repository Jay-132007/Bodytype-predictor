About The Project :

In this project, I developed a Machine Learning based web application that predicts a person's body type using physical body measurements.

The system takes:
- Height
- Weight
- BMI
- Body Fat %

as input from the user and predicts whether the person is:
- Ectomorph
- Mesomorph
- Endomorph

I used:
- Random Forest Classifier for prediction
- Train-Test Split for model training and testing
- Streamlit for creating the interactive web interface

The project also includes:
- user-friendly UI
- fitness images
- prediction result display
- model accuracy information

This project demonstrates the practical implementation of Machine Learning, classification algorithms, and web application development using Python and Streamlit.
